## 1. 软件概览

- 名字：**Infinite Tokens**
- 形态：**C++17 + Qt 6（Qt Quick / QML）** 桌面应用，目标跨 Windows / macOS / Linux。
- 定位：一个把**学习资料、作业、AI** 收在一起的「一站式」学习助手。
- 当前阶段：**页面骨架 + 部分界面功能已落地，业务功能基本未接**。
  - 已实现：主页面骨架、三套主题、AI 服务商注册表与图标、AI 对话面板（假数据）、
    设置页界面、账号菜单界面、AI 指令总线（服务端下发的本地指令已能执行）。
  - 未实现：真实 AI 调用、API Key 保存、登录与同步、新增学科、背单词、作业、生词收集等。

## 2. 主页面

主页面就是**一个内容卡片**，卡片内部再分「学科侧栏 + 主内容区」，外加一个顶部通栏头部。
没有左侧全局图标栏（早期误读草图加过，已删除）。

```
┌──────────────────────────────────────────────┐
│ ☰ 更多选项                    [AI] [用户头像] │  ← 卡片头部
├──────────────┬───────────────────────────────┤
│ ✚ 数学       │                               │
│ ○ 物理       │        主内容区（留空）        │
│ ⚗ 化学       │                               │
│   ⋮ 可滚动   │                               │
│──────────────│                               │
│ 预留区(待定)  │                               │
└──────────────┴───────────────────────────────┘
```

### 2.1 卡片头部（顶部通栏，不滚动）

| 位置 | 元素 | 功能描述 |
| --- | --- | --- |
| 最左 | ☰ 更多选项 | 收纳这个卡片层面的次级操作/菜单，**具体条目待定**，当前无行为 |
| 右端（左起第 2） | AI 按钮 | 显示**当前服务商**的图标；点击**打开对话面板**（见 2.4） |
| 最右 | 用户头像 | 单人剪影；点击**弹出账号菜单**（见 2.5），用于登录不同账号同步各自资料 |

### 2.2 学科侧栏（卡片内左侧，宽 220px）

- 每一行 = **学科图标 + 学科名**，图标按学科区分，用户不读文字也能认出。
- 当前学科是**写死的假数据**：`数学 / 物理 / 化学`（`math / phy / che`）。
- 点击某行 → 该学科高亮选中；列表可独立滚动，溢出时右侧出现细滚动条。
- **新增学科**的入口尚未确定（不在头部、也不在侧栏底部），属于待办。
- 侧栏底部有一块「**预留区（待定）**」，含义未定（候选：资料树 / 标签 / 说明）。

### 2.3 主内容区（卡片内右侧）

- 当前**刻意留空**，只显示「主内容区（界面骨架，暂未接入）」占位文字。
- 计划：选中不同学科后在这里渲染不同内容（学科专属功能 + 资料视图），尚未实现。

### 2.4 AI 对话面板（ChatPanel）

- 点头部 AI 按钮 → 从右侧滑出，参考 GitHub 右上角 Copilot 聊天面板。
- 结构：顶部标题 + 中间消息列表 + 底部输入框；可输入、Enter 发送。
- **尚未接真实模型**：发送后只回一句说明，不会真的调 API。
- 目标：用自然语言让 AI **操作软件内的所有东西**（换学科、换主题、导入资料等），
  通过「服务端下发本地指令」实现（见 2.7）。

### 2.5 账号菜单（AccountMenu）

- 点头像弹出，含「**设置…**」入口，点击进入设置页（外观导航项）。
- 「换头像」等其它登录/切换账号能力**尚未实现**（依赖服务端方案）。

### 2.6 主题 / 服务商（主页面间接体现）

- 主题三套：`dark`（深色）/ `light`（浅色）/ `star`（星空），启动参数 `--theme` 可指定。
- 头部 AI 按钮图标跟随**当前服务商**变化，默认 **DeepSeek**。

### 2.7 AI 指令总线（已实现，无界面）

- 客户端**不直连厂商、不存厂商 Key**，所有请求经服务端转发，服务端返回 `{reply, commands}`。
- 客户端只执行白名单指令，当前支持：`ui.set_subject`、`ui.set_theme`、`ui.set_provider`、
  `ui.open_chat`、`ui.close_chat`、`ui.open_settings` 等。
- 服务端本身**尚未实现**（协议已定义，见 [design-ai-protocol.md](design-ai-protocol.md)）。

## 3. 设置页（SettingsPage）

从账号菜单「设置…」进入，**全页覆盖**主页面，左侧导航 + 右侧内容分栏，参考 GitHub 设置页。
四个导航项：

| 导航 | 能设置什么 | 状态 |
| --- | --- | --- |
| **外观** | 选择主题（三套，动态列出），选择后**立即生效** | 已实现，可切主题 |
| **AI 服务商** | 单选服务商（DeepSeek / Claude / GPT / Gemini / 通义千问 / 自定义），头部 AI 按钮图标跟随变化 | 已实现选择与图标；**API Key 输入与持久化未做** |
| **账号** | 显示用户名 + 头像，可换头像 | 仅界面；**登录/同步/切换账号未实现** |
| **关于** | 只读信息：版本、界面框架、当前主题、当前服务商 | 已实现 |

### 3.1 外观（可设置内容）

- 主题**单选列表**，每项带该主题配色的小缩略图。
- 说明文字：界面结构不随主题变化，只换配色。
- 已内置 `dark / light / star` 三套；主题由 `src/ui/theme.cpp` 的表驱动，
  新增主题只需加一份配色，不改界面结构代码（已具备扩展接口）。
- **明暗模式切换方式未定**（跟随系统 / 手动 / 两者都支持）。

### 3.2 AI 服务商（可设置内容）

- 服务商**单选列表**，每项带品牌图标，选中项有单选圆点。
- 说明文字：所有请求经我们的服务器转发，客户端不直连厂商、不存厂商 Key。
- **缺失**：API Key 输入框、凭据持久化、以及「用官方服务端 / 自填 Key」的最终决策。

### 3.3 账号（可设置内容）

- 显示当前用户名（默认 `Learner`）与头像，点头像可换照片（本地，不持久化）。
- 说明文字：数据跟着账号走，不跟机器走。
- **缺失**：真正的登录、多账号切换、资料同步（依赖服务端方案，见 [server-plan.md](server-plan.md)）。

### 3.4 关于（只读）

- 版本 `0.1.0（页面骨架阶段）`、界面框架 `Qt 6 / Qt Quick`、当前主题、当前服务商。

## 4. 已实现 vs 未实现（现状速览）

### 已实现

- 主页面骨架（卡片 + 头部 + 学科侧栏 + 主内容区留空）。
- 三套主题 `dark / light / star` + 可扩展主题表。
- AI 服务商注册表（六项）与头部图标联动，默认 DeepSeek。
- AI 对话面板（界面 + 输入，未接真实模型）。
- 设置页四导航（外观 / AI 服务商 / 账号 / 关于）。
- 账号菜单（含「设置…」入口）。
- AI 指令总线（服务端下发白名单指令可执行）。

### 未实现（已登记在 TODO，详见 [TODO.md](../TODO.md)）

- 真实 AI 调用与服务端实现。
- API Key 输入与凭据持久化。
- 账号登录、多账号切换、资料同步。
- 新增学科与学科数据模型。
- 主内容区渲染（资料视图 / 学科专属功能）。
- 背单词模块（学习 + 复习，5 个记忆点）。
- 作业提交与切题、报题号提问。
- 学习会话（开始 / 结束）。
- 生词收集与单词本联动。
- 侧栏底部预留区用途。
- 明暗模式切换入口（设置页里的切换控件）。
